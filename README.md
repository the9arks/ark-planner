# ARK PLANNER — трекер жизни (телеграм-бот + Mini App)

## Что нужно, чтобы запустить

1. **Токен бота.** Напиши в Telegram боту `@BotFather`, отправь `/newbot`.
   - Имя (отображается в чате): например `ARK`
   - Юзернейм (обязательно заканчивается на `bot`): например `arkplanner_bot`
   Он даст тебе токен вида `123456:ABC-DEF...`.
2. **Ключ Claude API.** Зайди на https://console.anthropic.com, создай API-ключ
   (Settings → API Keys). Это ключ для "мозга" бота — им он будет распознавать
   фото и текст.
3. Скопируй `.env.example` в `.env` и впиши туда оба значения:

```
TELEGRAM_BOT_TOKEN=твой_токен_от_botfather
ANTHROPIC_API_KEY=твой_ключ_с_console.anthropic.com
```

## Запуск

```bash
./venv/bin/python bot.py
```

Бот запустится и будет работать, пока открыт терминал. Напиши ему `/start` в Telegram.

## Что бот умеет сейчас

- Текстовые записи: "потратил 500 на такси", "спал 6 часов", "съел борщ"
- Фото чека → заносит трату
- Фото тарелки с едой → прикидывает калорийность
- `/summary` — сводка за 7 дней
